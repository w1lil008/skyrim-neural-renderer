# v0.1.0-prototype — draft pre-release

**Proposed release title:** Native depth and motion capture for Skyrim SE

**Draft prepared:** 7 October 2026. This is a local publication mock-up; no GitHub release or downloadable implementation has been published.

This prototype adds native D3D11 depth and motion acquisition to the working Skyrim neural-rendering experiment while preserving the existing Present/display-image path.

## Included in the implementation

- Capture of the depth and motion resources consumed at Skyrim's TAA boundary.
- R32_FLOAT depth and R16G16_FLOAT motion sharing with the actual neural command-list device.
- Checks for frame identity, source formats, resolution, numerical validity and the reviewed TAA shader.
- Original-input fallback when native capture is unavailable.
- Logs distinguishing supplied resources, parameter reads, failures, skips, F8 master state and GPU cost.
- A later history-reset repair for transitions between native and fallback inputs.

## Tested

The native-input Helgen test at 2560×1440 captured eight moving gameplay frames and recorded at least 9,851 neural calls, zero failed/skipped calls and a clean Quit to Desktop. The tester confirmed that F8 still visibly switched the effect off and on.

Paired-frame analysis supports the native motion convention. Controlled motion substitution also changed neural output with repeat controls. These are stronger checks than simply accepting resource pointers.

The history-reset repair was verified in a synthetic test after that gameplay run. It has not had another gameplay test, and an actual runtime failure was not deliberately induced.

## Still unresolved

Depth reaches the runtime, but zero-depth substitution produced no measurable RGBA8 output change, including a probe with history retained. This release does **not** claim proven depth use by the model.

Exact subpixel depth/display registration, the earlier intermittent shutdown error, other scenes, long sessions, resize, HDR, HUD/transparency and multiple True NR Layers remain unvalidated. ENB is outside this prototype's current scope.

## Performance context

On the recorded **NVIDIA GeForce RTX 4060 Ti** test adapter at 1440p, sampled active medians were about **17.59 ms for the full neural pass** and **0.39 ms for optical flow**. Native snapshots measured 0.15 ms, conversion 0.20 ms, and diagnostic readback 2.24 ms when sampled. Readback runs every 60 copies plus bounded capture bursts. These are separate timestamp measurements, not an overall added-frame-cost benchmark or an FPS promise.

## Mock-up assets

The local package includes this draft, README, development and validation documents, a sanitized evidence summary and the actual Helgen buffer-inspection image. It contains no playable Skyrim files, neural runtime binaries or built mod DLL.
